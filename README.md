# General Simplex Implementation in Rust

A Rust implementation of the general simplex algorithm for solving linear programming problems.

## Requirements

- [Rust](https://www.rust-lang.org/)
- Cargo, which is included with the Rust toolchain

## Building

Clone the repository and navigate to its directory:

```bash
cd General-simplex-implementation-in-Rust
```

To build run the command:

```bash
cargo build --release
```
The executable will be located in:

```bash
target/release/simplex_algorithm_implementation
```
